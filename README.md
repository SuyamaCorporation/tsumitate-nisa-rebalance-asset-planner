# 積立NISA リバランス資産配分プランナー

国内株式・外国株式・国内債券・REITの目標配分比率と現在評価額を入力し、現在配分と目標配分の乖離をドーナツチャートで視覚化します。月額積立額を入力すると各資産クラスへの推奨購入金額とリバランス完了までの予測期間を算出します。入力内容はlocalStorageに保存・読込でき、想定利回りを変えた長期成長予測（10/20/30年）もバーチャートで確認できます。

## 機能
- 4資産クラス（国内株・外国株・債券・REIT）の目標比率と評価額入力
- 現在配分・目標配分のSVGドーナツチャート比較
- 乖離率テーブルと月額推奨購入金額の算出
- リバランス完了目安の月数・年数予測
- 想定年利回り入力による10/20/30年複利成長予測
- 元本と評価額の水平バーチャート
- ポートフォリオのlocalStorage保存・読込
- 元本割れリスクの免責表示
